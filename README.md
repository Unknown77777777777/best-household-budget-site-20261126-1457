# Duit Kita

Situs anggaran rumah tangga statis untuk keluarga Bima &amp; Sari, Bandung — November 2026.
Uang keluarga, rapi dan tenang. Dasbor, pemasukan, pengeluaran, anggaran, tabungan, dan
laporan dalam satu halaman dengan hash routing; semua data tersimpan di peramban
(`localStorage`, kunci `duitkita-v1`) dan bisa direset ke data contoh. Tanpa network,
tanpa build step — buka `app/index.html` lewat server statis apa pun.
